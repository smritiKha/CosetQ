# ClosetIQ ✦

An elegant digital wardrobe and personal outfit studio built with React and Vite.

## Run locally

Install Node.js 20+ then run:

```bash
npm install
npm run dev
```

## Deploy with GitHub Pages

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **GitHub Actions** as the source.
3. Open **Actions** and run the **Deploy ClosetIQ to GitHub Pages** workflow (or push a commit to main).
4. Once deployment succeeds, visit `https://smritikha.github.io/CosetQ/`.

This is a frontend prototype: wardrobe items and photos use browser localStorage, outfit combinations are category-based rather than AI, and shopping/virtual fitting are planned for later versions. Do not upload sensitive images.
